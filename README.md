# 躁鬱睡眠カレンダー

`index.html`をブラウザで開いて使える、気分・睡眠の記録アプリです。インストールやサーバー起動は不要です。

- 月間カレンダーで気分（躁／やや躁／安定／やや鬱／鬱）、起床・就寝時刻を一覧
- 日付をクリックして記録・編集・削除。メモや気分のみの記録も可能
- 選んだ日付に起床・就寝時刻と昼寝の開始・終了時刻を記録。昼寝のみ、開始・終了の片方のみでも保存可能
- JSONファイルへのバックアップと復元。同じ日付は確認後に上書き
- スマートフォン対応、キーボード操作対応

## 保存について

データはlocalStorageに保存され、外部へ送信されません。ブラウザ間・端末間の自動同期はありません。ブラウザのデータ削除やプライベートモード終了で消えることがあります。定期的にバックアップしてください。

ファイルを直接開く場合、localStorageの扱いはブラウザによって異なります。同じ場所のファイルを同じブラウザで使用してください。ファイル移動やブラウザ変更の前にはバックアップし、変更後に復元してください。保存が許可されない環境では画面にエラーを表示します。

## 構成と確認

HTML / CSS / JavaScriptのみで動作し、React・API・DB・外部依存は使用していません。静的ホスティングでも利用できます。

テスト：`node --test --test-isolation=none app.test.cjs pwa.test.cjs`

## PWA・ホーム画面への追加

プロジェクト全体をGitHub PagesなどのHTTPS環境に配置してください。サブフォルダへの配置にも対応しています。初回のオンラインアクセスでキャッシュが完了すると、オフラインでも起動・記録できます。ファイルの直接表示ではPWA機能は利用できません（開発時はlocalhostでも利用可能）。

iPhoneではSafariの共有メニューから「ホーム画面に追加」、対応するPC・Androidブラウザではブラウザのインストール機能を使用します。アプリアイコン・favicon・Apple用アイコンを設定済みです。記録は引き続き端末内に保存します。

更新時は `sw.js` の `VERSION` を変更し、ファイル名やCSS・JSのクエリ文字列を変更した場合は `FILES` も合わせて更新してください。新しいキャッシュを準備した後、アプリと関連タブをすべて閉じ、開き直すと更新されます。入力中の強制再読み込みは行いません。他プロジェクトのキャッシュや記録データは削除しません。

アイコン原稿は `icons/icon.svg`、PNG生成用スクリプトは `scripts/generate-icons.ps1` です（WindowsのSystem.Drawingを使用）。

このアプリは日々の主観的な気分を記録するためのもので、診断を行うものではありません。
